## 四块黄障碍与原路线

几何依据：任务书图2，3000×3000 mm；每块 150×100×25 mm。原点为场地中心，红方放置区在 +y。四个闭矩形为 |x|=250～400 与 |y|=560～660 的组合。依据是门槛内侧 |y|=1140、图示间距 480、块纵长 100，左右净口 500。不得把俯视尺寸当车轮能爬 25 mm 的证据。

用 `python check_clearance.py --radius 100` 可重算。连续线段到矩形最短距离，不跳过薄障碍；接触也算命中。示例 100 mm 是敏感性参数，**不是实车尺寸**。轴向距离与到矩形角的欧氏距离不是同一指标。

| 环节 | 检查结果与范围 |
| --- | --- |
| 四角开局、取物及暂存 | 理想对角线最近角净距约 113 mm；开爪、偏移及原地旋转另算扫掠。抓取点可变，不能用场心出发替代所有轨迹。防守点约 (±700,±550)，防守放下退 350 后从实际位姿返①；应随实际朝向复测，不把防守称作无碰撞。进攻放下退 100 后在 |y|≈590 横移到 x=±400，红蓝及四出发区按名义路径车中心均穿块。 |
| 正式载荷从场心去预备点 | 物资/伤员分区镜像 x=±150，|y|=540，容差横 ±100、纵 ±50。由场心直达名义点最近约 102 mm；从其他抓取位置斜进、粗转精的制动、朝向和容差会改变扫掠。纵向外缘可到 |y|=590，横向外缘可到 |x|=250，容差矩形本身就含接触位置。 |

## 两种“微调”怎样分清

1. **定位平移：** 上位 reason=safe_zone_staging_navigation，0x03 STAGE NAV，H 是场地平移方向、D 是剩余毫米；粗段最高 800，近段精定位 250～600，180 mm 范围内按轴容差去掉已到的分量。抓取后先看实际起点；若尚未收到 D=0、D 长时间不降且车侧贴块，优先查几何碰撞或轮滑，不是安全区框没对正。
2. **门口视觉横移：** 已经历 D=0、载荷审核或许可复用、航向对准；0x04 ALIGN 带视觉位，reason=safe_zone_visual_align_wait。新框目标点相对画面中心 640 的横差 >64 px 开始、≤32 px 结束；F405 按 270～400 mm/s 保航向横移，未完成时不放行。看日志是否有有效新框、持续同号误差/实际横移命令及实际侧向位移。只看 mode=10/11 不能拆出阶段；要看命令标志与 reason。若是 SAFE_CORRIDOR_UNAVAILABLE、等待新框或姿态未转正，不在执行有效横移，不能触发脱困。
3. 进入门前后，判障前还要检查 y 相对预备线 ±50 mm；超出常会保留当前 x 再导航补 y，回到审核/对准。如果手推前进只打破死点，它可能成功，也可能随后走补位回原处。上位机视觉允许才发 ENTER；不伪造到点、视觉 DONE、送达或改写上报位置。原流程的危险物/侧挤/扫障针对识别对象，不是四个固定黄块的全车防碰撞规划。

## 两场的取舍（仅候选）

- 第一场 FinalRun 保守：不改程序和规则；允许选择原有防守策略避开已知进攻穿块段。不要承诺防守返程全安全。赛第一场的默认优先级是**已经核对并能回退**，不是调参更多。
- 第一场 FinalRun1 只在实测后考虑**一个分支**：持续存在同方向有效指令且沿该方向确实无进展，区分 NAV/视觉横移，排除转头、等图、刹车和已到容差；仅在有扫掠余量时沿刚才平移反退一次（30 mm 是候选，不是必清距离），再以原阶段的新 H/D 或新像素误差重试。记录 nominal→退让→重试/恢复；一次仍不通则使用现有人工暂停/回退，不反复顶、不把障碍升级为送达。不改全车限速、不 1500 强推，不固定转 90°。若总因同一目标线重碰，**此法不算解决**。阈值要用一次正常带货横移与一次已知受阻记录标定；不把单轮不动、三轮总转数、编码器打滑误当车体进展。
- 第一场下位不能独自永久前移预备线/放宽上位像素阈值，既保证配套又让上位永远不补位。若试“先前挪再横移”，只在相同上位动作仍有效、真实 y 不越窗口、并经扫掠验证的条件下研究；否则留给第二场。只有 x 中心归中并不意味着后续在 y=540 横移安全。
- 第二场 FinalRun2：在**新上位代码实际部署并报 SHA 后**单独配套。优先考虑“场心附近可用通道→经膨胀障碍的中缝→低位外廓整车越带后分半区”，同时规划退出/返搜。中心口理论半宽 250 mm；实际净裕量扣除朝向对应低位外廓与定位偏差。若障碍外沿到门槛的 480 mm 空间放不下车、载荷、转身/制动余量，不照此硬设新预备点。放置前的相机视场、入区推距及越线风险要随新起点重算，不能只改一个 y。
- 照片备忘已归档为**待决策**：取物后是否经中心、缩短门前距离/放宽多少、防守返程/搜索点是否保持、只留第一个扫障点、速度、是否放弃伤员。均未在任何版本实施；放弃伤员有得分代价，“只留第一个扫障点”也须先明确指入口扫障点还是搜索点。第一场继续用四类真实载荷审核，1121 物料模型不换。模型路径/校验值可查，权重本体不在此 Git 提交内，不能声称已现场验过。
