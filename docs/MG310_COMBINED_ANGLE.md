# MG310边平移边转固定角度（2026-10-16）

原Motor_MoveSpin(speed, direction, yaw_speed)是连续速度接口，direction是平移方向，不是车头要转的角度。保留其语义，不将旧调用的参数单位静默改变。

新增Motor_MoveSpinAngle(speed_mm_s, direction_deg, turn_deg, max_rate_dps)：

```c
MotorTurnStatus result = Motor_MoveSpinAngle(300.0f, 180.0f, 180.0f, 60.0f);
```

表示沿开始时车尾指向的地面直线移动，车头逆时针转180度，目标平移速度300mm/s、最大角速度60度/s。turn_deg正值为场地逆时针，区别于底层驱动转角接口的正负定义。

- speed支持正负，绝对值不超过500mm/s；负速度使平移方向反转。
- direction允许任意有限角度，内部归一化；0为起始前方、90为起始左侧。
- turn范围-360至360度；使用未取模IMU累计角，不走最短角捷径。
- max_rate范围20至90度/s；很低速度的大角度请求可能触发现有10秒动作超时，不自动延长。
- 参数仅在启动时锁定，控制在电机10ms更新中执行，重复调用不会重启。
- DONE或FAULT保持至Motor_Stop；Motor_Stop取消后允许发起新动作。FAULT只结束本次动作，不设置全局堵转/方向故障。
- 临近目标同步降低平移和旋转；最后10度不再请求继续平移（按加减速逐渐停），超调后不继续平移追角。
- 角度进入1度范围后制动，等待新鲜IMU角速度不超过3度/s且三轮测速为0持续150ms才DONE。
- STOP中止后，不自动恢复未完成角度；本接口不提供保留原点的PAUSE续跑语义。
- 无法保证实际1度精度，必须先做架空方向检查及落地小角度对照，再验证大角度动作。

MG310组合运动试调：平移加速度900mm/s²、旋转轮缘加速度270mm/s²；横向偏差P为1.0，纠偏限幅60mm/s。取消未经当前电机实测的55ms航向预测，使用当前测量方向。
转角位置系数2.5/s，减速包络120度/s²，末端最低请求8度/s作为起步试调；不是厂家标定值，低速卡滞仍可能需要实车进一步调整。
轮速需求过大时同比缩放平移和旋转，不再仅压缩平移。共用基础前馈100permille、速度PID 5/0.12/0和60%上限，PID额外倍率仍为1.0。

现有APP_ENABLE_MOVE_SPIN_TEST演示改为调用此定角接口，但开关继续为0，没有自动运动或新运行模式。
刚改好的NormalRun分段开局、固定投送航向保持、分离弧线均不切换至该新接口。
没有新增上位机二进制命令或程序器文本命令；需由明确的C调用使用，不要在串口里直接发送函数名。
