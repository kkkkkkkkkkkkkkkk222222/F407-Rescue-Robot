## 1. 最终整体流程

120度/105度两层旋转搜索→锁定物体或物堆→固定当前搜索俯仰、原地水平对准→mode52等待该角度下的新图测距→发送一次定距接近请求→mode53编码器定距接近→相机降到140度并完成原250ms准备→普通mode21或聚集mode38以200mm/s补充接近、最多200mm→累计两帧夹内审核→抓取/分离→原运输流程→mode48核对实际载荷与目的地→必要时换半区或分离→重新定位/视觉ALIGN→直线ENTER投送。

主接近流程不再以摄像头达到125/130度作为前进和低头条件。扫障42/44仍使用其原有局部接近流程，不能误套普通定距请求；橙色49/50、INITIAL_STASH、mode48及mode51保持各自语义。

## 2. 搜索、对准及新距离请求：必须同步实现

### 下位机已实现

- 搜索低层角从90度改为105度，高层120度不变；速度仍为200mm/s轮端切向速度。
- 普通/聚集APP进入时锁定最近的105或120度，保持相机俯仰，停止平移，用现有视觉车头PID水平对准。普通误差24px、聚集40px，沿用原阈值。
- 固定相机后至少250ms的新目标报告才用于放行对准，不将切换角度之前的报告直接当作到位证据。
- 对准后在原0x17状态上报mode52（APPROACH_RANGE_WAIT），停止轮子，保留105/120度，等待新测距结果。
- 接收合法距离请求后上报mode53（APPROACH_RANGE_MOVE），使用现有Motor_MoveDistanceLinear编码器/IMU控制。最高500mm/s，最后250mm向200mm/s减速；距离在首次接受时锁存。
- 距离走完才进入140度准备，完成后进入21/38夹内观察。0mm是合法请求，表示已经到预计位置，直接准备140度，不能把距离无效伪装成0mm。

### 线上编码

不增加帧类型或opcode，仍为0x1D上下文+同SEQ紧邻0x18任务帧，COMMAND=9 APPROACH_TARGET。

| 字段 | 普通APP像素请求 | 定距APP请求 |
| --- | --- | --- |
| FLAGS bit6 | 0 | 1，新增APPROACH_RANGE=0x40 |
| FLAGS bit4 | 0 | 1，DISTANCE_VALID=0x10 |
| P2/P3 | 图像X像素 | 首次锁存的应前进距离mm，0..2500 |
| P4/P5 | 图像Y像素 | 本次测距对应的固定俯仰角，10500或12000，单位0.01度 |
| P6/P7 | 沿用像素APP | 必须0 |
| bit5 | 聚集目标标志 | 与本次像素APP保持相同CLUSTER_TARGET |

两种请求均带VALID和相应阵营位。定距APP不得附带DRIVE_STRAIGHT、USE_FINAL_HEADING或TARGET_RIGHT。APPROACH bit6和DISPERSE SIDE_VALID虽数值相同，含义由opcode区分。

定距请求只允许在本次mode52、同task_id、递增的新action_id下首次发起，并使用对准后新采集的图像帧号。F407检查本地新frame、接收时刻、测距角与当前固定角一致；真实采集时刻仍需上位机检查，不能把收到状态前的旧图当作对准后图。

同距离请求接受后，反复发送必须保持task/action、距离、测距角及flags一致，不要把距离更新为剩余距离，不要为每个新图重新分配动作号。下位机拒绝中途改距离，重复包不重设编码器起点或阶段期限。mode53无需目标始终可见；可重发原定距请求或发送相同已接受上下文的HOLD心跳。人工PAUSE保留暂停，恢复不重置行程。

## 3. 140度补进与有限恢复

- 低头和原250ms准备后，普通和聚集均200mm/s，共享本目标额外200mm额度。额外额度只在定距阶段完成后的140度观察开始，不把前面的定距路程算进去。
- 初次纯空爪继续前进，途中确认非空就停止推进，进行抓取或选侧分离。真实稳定空爪且200mm用完时停止前进、清本目标观察并进入SEARCH，不永久等原目标。
- 无图/不可靠观察不是空爪；额度用完后等待既有审核决定或有限恢复，不因为旧包无限向前。
- 对准6秒、mode52等有效距离5秒、mode53定距12秒超时，进入既有mode24恢复，再搜索。新APP/重发不续期。人工PAUSE时间不计入这些期限。
- mode53通信心跳超过500ms暂挂当前有限动作，保留起点；达到2秒仍未恢复则结束本轮接近进mode24。人工PAUSE不作为失联计算。
- 审核仍有原15秒有限恢复路径，上位机保持对应17秒交接出口。不要新增超时即永久FAULT，也不能把正常有限恢复变为ABORT。

## 4. 累计两帧：短暂漏检不重新起步

F407已将活动审核中的短暂无观察包改为“撤销READY/VALID授权，但保留未过期样本”，不更新时间或audit_id。第二个不同新帧在500ms窗口内、距首个有效样本至少100ms，且类别/数量/角色一致时，可累计完成两帧。

例如：GREEN1→无观察占位→GREEN1，可累计。GREEN1→GREEN2→GREEN1、目标/阶段/俯仰改变、机械分离后均需要重新形成证据，不能将矛盾物块忽略。危险、未知、混装的真实审核不作为漏检跳过。

新图缺失时取消STABLE和pending放行，不GRAB/不NAV。缺图后重发原图旧STABLE不能恢复授权，必须收到新的真实图；重复frame/audit_id不增加样本。原500ms证据失效、线上非法签名和目的地检查保留。INITIAL_STASH仍按真实非空、mode43仍按角色非空语义累计。

上位机需将“清除短暂无观察的授权”和“重置证据样本”分开：修改_record_audit_frame、_audit_observation_wait、pending审核、分离侧票及扫障审核的对应入口。保留同task/审核epoch内500ms未过期样本，采集时间仍用于100ms间隔；无观察期间不得继续发STABLE。上位机可以在500ms内累计，不能把多秒前的第一次识别与当前画面凑成两帧。

搜索任务层原本候选确认默认1帧；这不等于夹内两帧运输许可。安全区框冻结的3帧属于另一独立过程，本次不顺手改成货物累计两帧。

## 5. 投送前载荷/半区检查与分离续送

沿用原mode48，不额外叠加一套重复长审核。进入预备点后根据140度全爪实际载荷核对种类、真实数量、目的地及当前半区。半区正确与否必须看实际目标半区和新鲜位姿，不能只看车头90/270度。

### 载荷合法但半区不对

上位机现有目的地变化重导航逻辑保留，并补查“目的地标签没变但车辆实际在另一半区前方”的情况。到实际载荷对应的预备点再投送，不能只转向错误半区后直接ENTER。

使用新STAGE NAV，方向按车体到新预备点的H、D生成，完整方向flags用VALID|DISTANCE_VALID|STAGE_ONLY|DRIVE_STRAIGHT|USE_FINAL_HEADING|阵营位；F407先转向再直行，不主动加横移。到新点重新进入mode48和定位/视觉ALIGN，再走原ENTER。

当前下位机允许mode48合法审核后发STAGE NAV重新定位；允许目的地变化后重新审核，不直接把旧预备点通过的结果套到新半区。载荷目的地、INITIAL_STASH及扫障原载荷角色不可混用。

### 载荷多件/混合但可受控分离

下位机已增加mode48的带侧DISPERSE_PILE入口：需要新鲜两帧/STABLE非法非空审核、可靠选侧及剩余次数；必须带SIDE_VALID，保留右侧再加TARGET_RIGHT。mode48不接受无侧观察或FIRST_GREEN_BUMP冒充这次分离。

上位机在_transport_audit_output中对有可靠候选的非法载荷走现有两帧侧别与DISPERSE握手，不再直接落入双爪释放。保留绿色最多侧，伤员目的地则按目标类别及已有规则选择，实际类别和总数不能伪装。

下位机流程：48接受分离→本地曲线→mode35（动作完成，等待新审核）→上位机新CARGO_AUDIT使其进入普通mode21复核→仍非法且次数未满可第二次曲线→合法则GRAB闭爪→mode23抓后复核→mode22→重新导航当前实际载荷的预备点→mode48→ALIGN→ENTER。

上位机保留运输分离上下文和同堆两次总预算，不能分离后按首次搜索任务重新清零，也不改变投送计数。需要重建载荷manifest、目的地、预备点和安全区冻结框；新35/21/23结果不能误套旧48 pending。不要跳过重新闭爪，不能带着单侧张开就NAV。

mode48确认空爪、危险或无法安全分离的载荷走原放弃/恢复；两次实际分离仍非法按原退让返中心。无需新增通用ESCAPE。

## 6. 曲线分离参数与方向

统一“保留侧”定义：保留左侧＝左爪额外夹紧10度、右爪打开、后退同时右转；保留右侧镜像。RELEASE_LEFT表示打开左侧，与保留左侧相反，不可混用。手动单侧释放+YIELD也复用本地曲线。

F407新曲线先保持航向直退60mm解除挤压，再后退转向：第一次目标30度，第二次45度。弧段后退最高300mm/s，转向切向上限150mm/s；临近角度目标减慢后退，达到目标或有限弧段结束后逐渐消除转向，沿末端航向再拉开约70mm。末段最高500mm/s，速度仍受剩余距离和侧移边界限制。

取消原主动180mm/s横向平移指令，保留后退转向自然形成的弧线。弧段上限第一次250mm、第二次300mm；选择性曲线整体路程上限430mm，中心点相对起始方向的侧移预算120mm（较旧60mm增加），接近预算边界提前减速/结束复核，不为凑角度越界。47度为转向限制判据，不保证惯性下实测恰好不超47度。

曲线1.5秒没有可测位置/角度进展，或执行8秒仍未完成，结束本次尝试并进入原相机复核阶段，不永久锁停。人工PAUSE不计这些期限；两次实际接受的分离总预算不因暂停、重发、换侧而清零。上位机不能假定每次必走满430mm或必转满目标角，必须看动作完成和新审核结果。

在围栏前分离前确认上述车体/夹爪扫掠空间可用；若需退到空旷处再分离，由上位机在正式预备点路线中规划，不能临时发送未审核的未知动作。车体中心侧移预算不等于整个夹爪扫过宽度。
