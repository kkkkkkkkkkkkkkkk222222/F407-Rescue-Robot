## 已复现并修复的代码缺陷

生产Task/mechanism夹具复现：过滤动作已设82° → MOTOR故障进入原RECOVERY_WAIT并清single_filter_active →
恢复后真实黑CORE审核/重新GRAB/抓后复审 → 普通NAV获准，但S1仍是82°。
普通运输原来依赖上一步已经恢复85°；过滤被中断时会跳过其恢复阶段。

最小修复：task_begin_close_claw进入普通合爪时明确调用原Lift_SetTravelPosition()，回到既有85°。
沿原合爪与审核流程完成，没有新计时门/握手/ISR/FAULT，不改变过滤82°、放下65°、起步61°或偏移。
原测试文件加入该故障恢复回归；修后同路径普通黑CORE NAV为85°。
这是确定存在且能解释高度偏低的路径；尚无本次掉物过程的动作日志，不能把它断定为唯一实车原因。
