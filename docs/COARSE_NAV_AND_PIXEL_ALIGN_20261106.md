# F405 本地粗导航与像素对准

本轮从下位机 `b2dd1d22f86b6d9477d3615fd31b6e0c936f11e2` 增量修改，
核对上位机 `5051376857f5bdfa66a4c2a07786a17404d3a61b` 的两份交接说明。
RDK报告的两轮实跑为 `1703394/source_dirty=1`；它不是本轮构建/实烧身份。

## 实现与影响

- `nav_follow` 的 STAGE、藏点 NAV（持物及空爪返藏点）、RETURN 在原任务内部走
  对正、粗段、原刹车、低速全向修正。旧 ENTER 推进及非STAGE旧投送分支不改控制流程。
- 仅新接受的 NAV/RETURN task/action、配置会话重建或任务初始化清粗段基准。
  起始 D/H 在该动作首次进入导航时锁存，实际驶出时锁存本地 Location 的 x/y；
  `progress = max(已有进度, (x-x0)*cos(H0) + (y-y0)*sin(H0))`。
  Location来自既有10ms真实轮增量和主gyro，既不积分目标速度，也不使用RDK位置跳变当轮里程。
  不改变F405公式，不清轮计数/全局里程，不重锚；反向运动或较大的新D不延长粗段预算。
- 高速/返中上限600mm/s。有效剩余为 `min(初始D-progress, 最新D)`，
  剩600mm开始线性减速，到本地剩250mm、或上位机D已≤300mm时刹停。
  初始D≤600mm及对正期间D缩至600mm内直接跳过粗段。
  保留原导航加减速1800/3000mm/s²及原转向稳定100ms，不增加定位/雷达等待。
- 刹停只等原 `Motor_Stop` 的6个10ms刹车周期，用只读 `Motor_IsBraking` 查询原状态；
  没有额外静止采样、等待计时器、ISR、诊断统计或停车锁存。
  随后复用 `Motor_MoveAngle` 的gyro航向保持和XY斜坡，按最新H减当前车头航向换算平移方向，
  速度 `min(200, max(120, D)) mm/s`。末端相位保持到动作结束，不退回高速或反复转车头。
- 同动作HOLD/人工PAUSE后恢复保留原粗段基准；新NAV/RETURN动作才可建立新段。
  粗段刹停只返回原内部WAITING，不设distance_done/nav_done，也不表示全局到点。
  STAGE及藏点仍认D=0，RETURN仍沿原80mm到点和后续返中搜寻/开爪规则。

像素对准源码核对：右侧目标产生CW请求、左侧目标产生CCW请求，未改任何符号。
电机零速滞环为3/6mm/s，原10mm/s请求高于启动零速阈值，不能将它说成必然被死区清零。
但原像素P=0.18、最小10mm/s只有约2.7rpm，负载起动能力尚无实际PWM/地面证据。
本轮仅将TASK_APPROACH原地对准最低请求试设为60mm/s（约16.4rpm），保留最大90mm/s、
400mm/s²输出斜坡、原轮速PI/PWM、视觉P/D、8/16px死区、24px/聚集40px到中条件。
到中即停车转原mode52；扫障及其运动中跟踪不提高最低转向请求。
这些速度和250mm预留是待实车确认的工程初值，不是制动距离或有效起动PWM标定结果。

## 上位机兼容与范围

- 无线上字段/TYPE/opcode变化，无需新合同、JSON或报文例子；保留0x18+0x1D、原状态回执及D/H语义。
- 上位机应在同一导航动作内更新H/D，不能为每帧分配新action，否则会被视为新动作。
  STAGE仍只在本身原位置容差内发D=0；不得将粗段停车当到点或提前投送。
- 保留合爪检查、mode51、人工STOP/ABORT、原取消/恢复及已接受动作的身份。
  此前待定的SEARCH提前RETURN兼容、其他年龄门或其他比赛业务不纳入本轮。
- 没有新增测试代码/程序、遥测、时间资格、周期查询或握手；不执行实车运动。

## 必要检查与尚未验证

- 检查采样链：Encoder_Sample10ms → Location_Update10ms → Motor_Update；
  主任务以原20ms周期读取本地快照，未改高频采样/发送链。
- 检查接受链：拒绝的请求不清基准，同一SEQ/不同SEQ心跳及同动作H/D更新不清基准；
  原阶段完成标志仍仅由原到点条件生成，不由本地粗段结束生成。
- 构建入口为 `NormalRun`、`MotionDebug`，F405/mode5，service分别2/1，UART4=230400/8N1。
  实际编译结果、嵌入SHA/firmware_id和dirty以本轮交付回执为准。
  既有Task.c两行空白保持在工作区，不夹入提交；因此实际构建如仍包含它们会如实报告dirty=1。
- 本轮未连接串口、未读取板端身份、未烧录、未执行运动。制动余量、对准最低起动力、
  停车后位置收敛及地面精度均待人工安排验证；构建成功不代表精度通过。
