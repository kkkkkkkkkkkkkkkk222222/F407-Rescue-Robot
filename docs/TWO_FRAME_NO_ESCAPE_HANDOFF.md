# 两帧审核、两次分离与取消自动脱困

日期：2026-10-16。下位机以本文件所在提交为准；上位机补丁基于codex/gamepad-teleop@e01ffb9。
本轮按用户要求暂不继续调整直行微偏、轮速PID或固定投送航向PI。

## 已改下位机

- 删除ESCAPE动作实现、派发入口及mode31完成回执，旧上位机发来的ESCAPE_MANEUVER明确拒绝。协议编号12保留为废弃编号，避免后续指令错位；不取消必要的安全区扫障。
- 普通、抓后、运输、扫障和mode51货物审核统一为两帧，不同audit_id、至少100ms间隔，并要求上位机STABLE。相同帧重发不能累积或延长证据有效期。T265恢复参考的三个位姿包不是货物审核，本轮不改。
- 分离上限由三次改为两次。第一次失败仍有可分离候选时，不因4秒决策等待直接放弃；第二次必须完成真实复核，仍非法才返中心。空爪、危险/无可保留目标或长期缺乏有效观察等情况仍允许提前结束，不能强行执行无意义的第二次机械动作。
- 单件夹紧20/15度，多件10/5度；依然按同侧同档计算，换档不重置总次数。第二次失败后的张爪、后退、闭爪、mode47返中心流程保持。
- 返中心和抓取放弃后的原地转向改为80mm/s轮缘速度；普通搜索75mm/s，等待返中心的扫描60mm/s。没有修改普通运输对准的默认转角速度。
- RETURN_CENTER在80mm范围内即可完成，不再必须等上位机精确报D=0；到达后沿现有开爪/SEARCH握手交接。
- 抓后相机稳定等待500ms降为250ms。闭爪、伤员半开后退和再次闭爪的机械确认时间未冒进缩短。
- IMU启动等待20ms、复位等待上限100ms；配置写入/读回有限重试；启动的ID/复位/配置失败最多重试三次，采样读取短暂失败在原期限内重试。
- 零偏校准仍使用2048样本和原角速度均值/方差检查；加速度改为至少95%样本及整段均值符合重力范围，不再因单次尖峰拒绝整段。真实持续移动仍不能作为零偏接受。
- 不新增永久故障锁存，不修改T265外参、运动极性或串口配对。

## 上位机配套补丁

文件：upper_patches/0001-fix-remove-automatic-escape-and-use-two-frame-two-at.patch

- 普通、抓后、扫障、运输、mode51和保留侧选择改成两帧；间隔100ms，总跨度100ms。
- 分离上限两次；SEARCH不因仅有一次历史分离就强制返中心。
- 单侧释放后的复核也进入候选侧筛选，可继续第二次选择性分离，而不是自动把复核失败当作必须双开。

- 返中心80mm范围确认到达后保持D=0，直到实际SEARCH交接；小幅位姿跳动不再次拉回高速对准。
