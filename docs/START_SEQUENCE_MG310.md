# MG310开局与视觉转向试调（2026-10-16）

NormalRun开局mode1保持，但不再同时平移和转180度：

1. 折爪状态保持起始航向，定距后退600mm，最高600mm/s。
2. 停车等待250ms，抬升至行走位置，夹爪仍收拢。
3. 原地转到初始场地航向+180度，轮缘切向速度250mm/s，使用现有转角接口及末段减速。
4. 停车等待250ms并完成开爪，再保持转后航向定距前进1100mm，最高800mm/s。
5. 进入原开爪/搜索状态。保留原开局路线意图，不自动导航到某个投放安全区。

每段使用独立定距原点，不以整段累计路径判断是否完成；纯转动不消耗前进距离。
这仍是编码器定距，不是T265实测离开障碍物的证明。首段打滑或障碍未通过时，应调整脱离距离和速度，不能保证固定600mm对所有实车条件有效。
开局仍使用现有30秒时限和mode51恢复出口，未新增故障锁存。

共用轮速PID仍为5/0.12/0，直行航向PID仍为2/0.005/0，60%PWM上限不变。
保留的MoveSpin接口额外修正倍率从1.8降为1.0，开局不再调用该接口。

视觉转向PD仅作MG310首轮实车试调：

| 参数 | 原值 | 新值 |
|---|---:|---:|
| P | 0.45 | 0.25 |
| D | 0.0100 | 0.0040 |
| 最小转向轮缘速度mm/s | 20 | 10 |
| 转向轮缘速度限幅mm/s | 175 | 90 |
| 转向输出变化率mm/s² | 1000 | 400 |

电机变化不能按扭矩/减速比直接换算视觉增益；新值属于减小过冲与坐标噪声响应的保守试调，不是实测最优值。近距离仍摆动时先看图像时延、坐标和转向符号，不继续盲目降低轮速PID。
未改相机PID、导航nav_yaw增益、橙色伤员49/23/50流程、T265外参或串口协议。
上位机按实际mode1结束等待，不再根据原“边退边转”时间推测开始搜索。
