# 给 RDK Codex 的三项导航交接

RDK 对照 e783f71。三轮设备自报 F405 0788360、dirty=1。以下为后续软件改动，实车效果待复核。

1. 安全区 STAGE。继续用 mode10、原任务/动作 ID、动态场地方位和剩余距离 D（mm）。
   F405 已移除首次 D+100mm 的累计路程停车及提前 DONE。RDK 在原预备点定位容差内持续发 D=0，
   等同一动作 distance_done 后进入 mode48 审核。保留现有容差。首轮现象与旧上限吻合，
   缺少直接命中记录；独立的 nav_progress.stale 分支仍按原逻辑执行。
2. INITIAL_STASH_NAV。RDK 继续发送到藏点的实时 D 和 atan2(dy,dx) 场地方位。F405 在持物、
   非 STAGE 的藏点 NAV 首次进入 300mm 时切到全向末端控制：保持进入平移时的航向，
   按当前车头把目标方位转成车体系向量，使用现有 Motor_MoveAngle 的轮速闭环和矢量斜坡。
   上位机沿用原到点/放货判定。复核末段时对照实际车身位移、轮反馈和 T265；轮反馈已参与 SDK，
   6.39m 累计轮程不能代替地面净位移。
3. ACQUIRE_SAFE_ZONE。修改上位机现有无框超时出口。建议只做一轮原地观察：
   以本次定位 ALIGN 的原航向 H 为基准，依次观察 H+8°、H-8°，最后回 H（按360°回绕）。
   用原 COMMAND=4 定位 ALIGN，沿用原 flags，两个位置参数为0，heading_cdeg 为绝对航向。
   同 task 下每次改变航向分配一个新 action_id，同一观察位的重发保持原 ID。
   F405 在定位 ALIGN 完成、视觉 ALIGN 尚未执行时接受新航向；已有转动期间上报 mode10，
   到位上报 mode11。使用已有匹配动作回执，避免把上一个观察位的 DONE 用到下一位。
   摄像头 S3 仍命令120°。每换视角清旧候选框/计数；用现有观察窗口和检测结果，
   侧向看到本方框即提前回 H。在 H 用新画面完成原三帧冻结、视觉 ALIGN 和走廊检查，
   然后才发 COMMAND=5。偏离入口航向的观察位仅供找框。
   一轮结束仍无框时进入明确的“需重新观察/人工调整”分支，停车并显示原因，
   提供重试/结束操作，避免每周期重新开始扫描或无限重复普通 ALIGN。
   建议保留失败时的一张原始图，核对实际俯仰、爪子遮挡和识别；角度回报仅是舵机指令值。

本次沿用已有报文、PID 和动作回执。三轮结束时的 signal_2、退出 ABORT 和 SDK 接受计数
都不能用来认定原始停滞原因或独立定位精度。
